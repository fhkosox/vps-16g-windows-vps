## 配置买多大：别照着"官方推荐 4 核 16G"无脑下单

《幻兽帕鲁》官方给出的推荐配置是 4 核 16G，最低 8G，如果人特别多最好 32G 以上。这个数字容易把人劝退，因为它默认的是满编 32 人的场景。

实际几个人开黑的服务器，跑起来远没这么夸张。雨云自己的开服文档也提到，帕鲁对 CPU 性能要求不算高，配置从 4 核 8G 起就够用。

按人数倒推比较靠谱：

- 2–4 个好友，原版不装 MOD：4 核 8G，内存是主要瓶颈
- 5–10 人，或者装了少量 MOD：4 核 16G
- 10 人以上，或者跑大型整合、长期有人挂机：8 核 16G 往上

硬盘方面，雨云游戏云的机型普遍是 30G 系统盘 + 20G 数据盘起步。帕鲁服务端本身体积不大，但存档会随游戏时间增长，长期开服建议留意数据盘占用。

这里有个容易花冤枉钱的点：**帕鲁不是吃单核的游戏**。雨云游戏云在 CPU 型号上分了高主频档，那些型号主要是给《我的世界》Java 版这种单核敏感的游戏准备的。开帕鲁服，同样的预算拿去加内存，比从 Gold 6146 升到 i9 14900KF 更划算。

## 计费模式：固定还是动态，这是最容易被忽略的一笔钱

雨云游戏云有两种计费方式，选错不会开不了服，但会多花钱。

**固定计费**：按月租走，不管 CPU 用多少都不额外收费。适合每天都会上线、服务器基本不关的长期服。

**动态计费**：基础费用更低，但按 CPU 实际使用量收"CPU 电量"费用。不同 CPU 型号的电量单价不一样，从 E5 2666v3 的 0.0005 元/电量，到 7950X、14900K 系列的 0.001 元/电量。举个便于理解的量级：以 2 核的 E5 2666v3 为例，1 元大约对应 2000 点电量，约等于 36% 的 CPU 占用连续跑 24 小时。

判断标准很简单：**每天玩超过 2 小时，选固定计费；只有周末临时开一下，选动态计费。** 动态计费在不使用的时段不产生资源消耗，碎片化开黑更省。雨云还支持按天计费，临时开一晚上试试水也不会被套一个月。

## 开服步骤（面板服，就是最快的那条路）

真要开服，面板服从下单到能进游戏，通常几分钟：

1. 注册并登录雨云账号，进入控制台的"总览"或"云产品"，找到游戏云入口
2. 点击购买游戏云，服务器类型选"面板服"，游戏类型选"幻兽帕鲁"
3. 选机型、核心数和内存（2–4 人建议 4 核 8G 起），再选固定或动态计费
4. 下单后回到"我的游戏云"，看到刚买的机器，点卡片或"管理"
5. 在机器信息里找到面板地址，用面板账号密码登录
6. 进面板后找到对应实例，点右侧"管理"进入实例控制台，点左侧"开启实例"
7. 等一会儿，控制台右侧会显示"对外地址"和端口，这就是你的服务器地址

把地址和端口发给朋友，他们就能进来了。整段流程里唯一需要记住的是那个地址格式：`地址:端口`，两个部分都不能漏。

## 开服步骤（Windows VPS，想要更多控制权）

如果你走 VPS 路线，流程长一点：

1. 购买游戏云 VPS 时，系统选 Windows Server 2019，并勾选帕鲁预装；已经买好机器的，可以在"重装系统或软件"里勾选帕鲁安装
2. 用 Windows 自带的远程桌面（RDP）连接服务器，用户名默认 `Administrator`，地址和端口在机器信息里
3. 连上之后，双击桌面上的「启动幻兽帕鲁服务端.bat」，服务端就跑起来了
4. 玩家在游戏里用 `你的IP:8211` 连接

想手动装而不走一键脚本的，用 steamcmd 拉服务端即可：


steamcmd +login anonymous +app_update 2394010 validate


装完后服务端在 `steamcmd/steamapps/common/PalServer` 目录下。

几个必须处理的细节：

- **端口映射**：雨云的 NAT 机型没有独立公网 IP，需要共用一个公网 IP，在控制台的"端口映射"里新建规则，把内网端口映射出去，外网端口会随机生成。游戏云 NAT 机型一般可以创建 15 条端口转发规则，只开一个帕鲁服绰绰有余
- **防火墙**：Windows Server 2019 默认关闭防火墙，如果你手动开过，记得放行帕鲁用到的 UDP 端口
- **协议别选错**：帕鲁走 UDP，只在防火墙或安全组里放行 TCP 是连不上的，这是新手最常卡住的地方

## 服务器设置改什么：`PalWorldSettings.ini` 实用项

想改服务器名字、密码、经验倍率这些，要动的是 `PalWorldSettings.ini`。

面板服里的路径是 `pal/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`，Windows VPS 上是 `C:\PalServer\Pal\Saved\Config\WindowsServer\PalWorldSettings.ini`。第一次打开通常是空的，需要把同目录上一层 `DefaultPalWorldSettings.ini` 里的默认内容复制进来再改。

几个常用的配置项：

| 配置项 | 作用 |
| --- | --- |
| `ServerName` / `ServerPassword` | 服务器名称和进服密码 |
| `ServerPlayerMaxNum` | 服务器人数上限 |
| `PublicPort` | 对外端口，默认 8211 |
| `ExpRate` | 经验倍率，最大 20 |
| `PalCaptureRate` | 捕捉成功率倍率，最大 20 |
| `DayTimeSpeedRate` / `NightTimeSpeedRate` | 白天/夜晚流逝速度 |
| `Difficulty` | 整体难度，可填 None、Easy、Difficult |

改的时候注意两件事：**文件内容不能换行**，要按默认模板的格式在同一个括号里改数值；**倍率要保留六位小数**，比如把 1.000000 调成 0.500000，而不是写成 0.5。改完保存后重启实例才生效。

还有一个坑值得单独提醒：`PalSpawnNumRate`（帕鲁出现数量倍率）看着很诱人，但调高之后服务器性能会明显下降，默认值不建议动。

## 几个容易踩的坑

**改完配置没生效**：面板服要在实例控制台重启实例，不是刷新页面。

**别人被攻击，你的服一起掉**：NAT 机型共用公网 IP，同一个 IP 被攻击时可能被牵连。纯私服问题不大，如果你要做公开的服务器，可以后期加购独立公网 IP（宿迁等地的独立 IP 独享防御，价格另计）。

**存档没备份**：帕鲁的存档在 `Pal/Saved/SaveGames/0/` 下的随机字符目录里，`Players` 文件夹里是每个玩家的数据。有人坏档时单独删掉对应玩家文件就能救回来，但删之前一定先复制一份。雨云的面板也提供备份功能，长期服建议定期用上。

**配置买小了要迁移**：雨云支持在控制台里升级配置、加装内存和硬盘、切换地区，不用重新开服搬存档。

## 常见问题

**4 核 8G 到底够不够？**
2–4 个好友、不装大型 MOD 是够的。人多或者装了 MOD，内存会先顶不住，升到 4 核 16G 是最常见的一步。

**一个月到底要花多少？**
按 2 核 4G 的 E5 2666v3 档看大约 65 元/月，Gold 6146 同配置约 80 元/月，4 核 8G 的高主频档会更高一些。年付 7 折之后成本明显下降，动态计费的碎片时间开黑还能再省一截。

**和用邀请码联机比，值不值？**
如果只是偶尔两三个人玩一两周，用游戏自带的联机就够了。如果你们是固定的小队、想长期玩、不想被房主的开机时间绑架，专用服务器才划算。

**开服之后能换游戏吗？**
面板服可以在机器信息里重装或切换游戏；VPS 更自由，重装系统或换服务端都行。
